# Oral Space

### Um site institucional desenvolvido com HTML, CSS, JavaScript e auxílio de Inteligência Artificial.

---

## 📌 O que é?

A **Oral Space** é um projeto de site institucional desenvolvido com o objetivo de compor o portfólio da **B2B Tech**.

O projeto simula a presença digital de uma clínica odontológica fictícia, apresentando uma proposta visual moderna, organizada e intuitiva.

A Oral Space é um projeto totalmente hipotético, desenvolvido para fins demonstrativos e sem vínculo com marcas ou estabelecimentos reais.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Inteligência Artificial como ferramenta de apoio ao desenvolvimento

## 🎯 Objetivo do projeto

Demonstrar habilidades em desenvolvimento front-end, criação de interfaces e construção de páginas institucionais, explorando conceitos de design, usabilidade e responsividade.
